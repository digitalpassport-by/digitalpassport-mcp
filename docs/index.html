Digital Passport Belarus — MCP Server & Open API

Public read-only Model Context Protocol (MCP) server and OpenAPI 3.1 REST API for digitalpassport.by.

Endpoints

  • MCP Endpoint (Streamable HTTP): https://digitalpassport.by/api/mcp
  • MCP Discovery: /.well-known/mcp.json
  • OpenAPI 3.1 Spec: /.well-known/openapi.json
  • Developer Docs: https://digitalpassport.by/developers/api
  • llms.txt: https://digitalpassport.by/llms.txt

Available MCP Tools

  • get_company_passport — Read company profile by 9-digit UNP or slug (JSON or Markdown).
  • search_belarus_companies — Search organizations by query, city, category, specialization, or market tenure.
  • explore_knowledge_graph — Explore sectors and specializations.
  • verify_belarus_unp — Validate a 9-digit Belarusian UNP checksum and registration region.
